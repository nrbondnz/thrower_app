# Ending Early

Part of [[Requirements Index]] → Basic play. **Status:** ✅ Built (device checks to come where noted)

## What's Wanted
A game (or competition) can be ended before all its rounds are played.

## What Exists Today
- **Play: Finish game** (asks first) ends a game after fewer rounds. A round in progress **counts**; two players are judged on **equal rounds** (the fewest either has played); the game is kept in History marked as finished early ([[story-checkpoint-game-history]] Task 5; device checks H0–H7 to come).
- **Quick draw: Finish match** (asks first) ends a match on the rounds won so far; level is a draw ([[story-checkpoint-quick-draw-match]]; device checks QM0–QM6 to come).
- **Reset game** (asks first) abandons a game; it isn't kept.
