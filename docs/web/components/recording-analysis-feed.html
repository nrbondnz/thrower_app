RecordingAnalysisFeed

Every frame of a recording, in order, for analysis, each stamped with its place in the clip. The picture may skip frames; analysis never does.

Type
TargetCamera
Defined in
lib/camera/recording_analysis_feed.dart
Used when
Quick draw on the recording, once Play is pressed

It decodes its own copy of each frame, one at a time, never ahead of the frame on show, so the result may come late but no frame is missed (Nigel: "analysis can come back with the actual result 1/2 second later").

It starts at go − 1 s, and starts again when playback restarts.
