Ring finder

Finds the painted rings in a frame as ellipses, one per ring edge, in a background isolate.

Used when
Find target (Calibrate), Tap the board (Calibrate), and each Quick draw tap

locateInFrame turns the frame upright (frameToRgb), then a rough pass on a shrunk picture finds the board, and a close-up pass at full resolution fits the rings. If nothing is found, each pass is tried again with the contrast stretched.

ColourRingLocator learns the board's two colours from the picture (the bull's and the next ring's), casts rays out from a candidate centre, and fits an ellipse to each colour edge with RANSAC, which outvotes rays spoiled by handles or cuts.

A tapped board none of that reads (stencilled rings painted in arcs on speckled wood: Mark's boards, 2026-10-21): _alignedStarts scores centres round the tap by how sharply the rings line up (the colour change averaged over every direction, by distance), takes the 3 best with a size from the bull's 1–4× multiples, then reads the edges with that size fixed. Only after a tap: Find target on its own is unchanged. Any fit with a bull under 6 working px is rejected as "Target too small".
