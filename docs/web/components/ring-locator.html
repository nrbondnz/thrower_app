Ring finder

Finds the painted rings in a frame as ellipses, one per ring edge, in a background isolate.

Used when
Find target (Calibrate), and each Quick draw tap

locateInFrame turns the frame upright (frameToRgb), then a rough pass on a shrunk picture finds the board, and a close-up pass at full resolution fits the rings. If nothing is found, each pass is tried again with the contrast stretched.

ColourRingLocator learns the board's two colours from the picture (the bull's and the next ring's), casts rays out from a candidate centre, and fits an ellipse to each colour edge with RANSAC, which outvotes rays spoiled by handles or cuts.
