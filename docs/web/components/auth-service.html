AuthService

The app's sign-in and backup, behind interfaces. Since stage 2 of the Accounts Roadmap (2026-10-19) it's AWS Amplify: Cognito (email, Google, Sign in with Apple) and an owner-only backup of kept games and names, in London (eu-west-2). Signing in is never needed to score.

Used when
App start (main: connectAccounts, if the build has the backend's settings); Home → Account

At start, main reads the deployed backend's settings from the asset assets/config/amplify_outputs.json (loadAmplifyOutputs; gitignored, one per branch). With them, connectAccounts adds the Cognito plugin, configures Amplify and returns an AmplifyAuthService, which overrides authServiceProvider. Without them, or if Amplify can't be configured, the provider is null and the app runs signed out, as it always has.

AmplifyAuthService follows the Hub's sign-in events (signed in, signed out, session expired, user deleted). The user's ID is the Cognito sub, never the email; the display name is the email.

The backend lives in the repo (amplify/, Amplify Gen 2). defineAuth: email, Google and Sign in with Apple (six secrets in the Amplify console, never in git), returning to the app on throwerapp://; each branch has a readable sign-in domain (throwerapp, throwerapp-dev). defineData: KeptGame and PlayerNameList, each owner-only (allow.owner()). Amplify Hosting deploys it from GitHub (amplify.yml: ampx pipeline-deploy): main is production, dev development. Its only web page is web_public/, later home to the privacy policy. Google, Apple and the backup are written and wait for the secrets before they deploy.

Sign-in shows only on Home → Account (AuthenticatedView), never in front of the app. AmplifyBackup is the signed-in user's backup on GraphQL (the API plugin is added only when the outputs have a data API: hasBackup). Delete account erases the backup, then the account; the phone keeps its games and names.

Nothing leaves the phone unless the build has the settings and the user signs in: then their sign-in goes to Cognito, and their kept games and names to their own backup.
