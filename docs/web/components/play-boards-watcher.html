PlayBoardsWatcher

Watches both boards for a whole game of Play, each on its own crop with the single-board throw detection, and reports every event with the board it came from.

Type
Class
Defined in
lib/game/play_boards_watcher.dart
lib/game/board_crop.dart
Used when
Two-target Play, once the boards are locked

Each board is cut out with cropToBoard (shared with QuickDrawWatcher) and watched by its own ThrowWatcher at Play's usual pace. Each event goes to GameNotifier.onEvent(board:), so a board's throws, collections and falling-out knives count only for its own player.
