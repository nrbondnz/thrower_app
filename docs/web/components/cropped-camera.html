CroppedCamera

A square of another camera's upright picture around one board, as a camera of its own, so single-board detection can watch one board of several.

Type
TargetCamera
Defined in
lib/camera/cropped_camera.dart
Used when
Quick draw, one per board

The crop is cut in the sensor's own layout (sensorRect), so a sideways Android frame is never turned whole: only the small crop is turned, by whoever reads it. Its frames are views into the source's bytes, with no copying.

The rotation is fixed when the crop is made, as the phone is on a stand. A frame the rectangle doesn't fit is skipped. All four sides are rounded to even numbers so YUV's half-size colour planes line up.
