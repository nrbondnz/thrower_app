TargetCamera

The one camera interface. A live camera, a recording, a board crop and a queue all deliver the same CameraFrame, so nothing downstream knows which it has.

Used when
Every screen and watcher that needs frames

A CameraFrame is plain data: width, height, format (BGRA, YUV420), planes of bytes and a timestamp. Vision depends on this data type only, never on a plugin.

now is the clock the camera stamps its frames with, so another moment, such as Quick draw's go, can be compared with frames on one clock.
