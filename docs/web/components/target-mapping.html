TargetMapping

Turns a pixel into normalised target coordinates: the centre at 0,0 and the outer edge of ring 1 at radius 1.

Type
Class
Defined in
lib/vision/target_mapping.dart
Used when
A tap on the locked target, or a knife's entry point

Along the ray from the bull's centre it finds each painted edge, and interpolates between them, so painted edge k maps to ideal radius k. A board whose paint isn't exactly to size still scores correctly, and a tilted board too.
