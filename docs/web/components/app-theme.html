AppTheme

The app's look (2026-10-23): a charcoal and amber palette, light and dark themes, and the shared cards and stat tiles. The camera screens are always dark.

Type
Themes + shared widgets
Defined in
lib/ui/theme/app_theme.dart
lib/ui/theme/widgets.dart
lib/main.dart
Used when
App start; Setup → Appearance; the phone switching dark mode

AppPalette has a dark and a light set of colours; the light one is darkened to read on a light background. AppTheme.light() and dark() build Flutter themes from them, and ThrowerApp passes both, with themeModeOf the Appearance setting.

The camera screens (Play, two-target Play, both Quick draws, Calibrate, the score pad) are read from the throwing line, so each is wrapped in CameraTheme: AppTheme.cameraDark, whatever the setting.

Design: docs/thrower/AppDesign/ (App Design Index).
