PlayerNamesStore

The players' names last used, kept on the phone so the setup screen fills them in next time.

Type
Interface + file store
Defined in
lib/settings/player_names_store.dart
lib/providers.dart
Used when
App start (load); a name set on the setup screen or with Quick draw's Names (save)

A name is a label on a seat for one game (stage 1 of the Accounts Roadmap): no player list, no history of their own. Friends with their own accounts come later.

FilePlayerNamesStore keeps them in player_names.json in the app's own support folder, beside the history, written through a .tmp file, one save at a time. A file that can't be read gives blank names; a failed save is ignored. They're a convenience: nothing else depends on them.

It lives in its own edge folder, lib/settings/, because names aren't history. Signed out, nothing leaves the phone; signed in, set also saves them to the backup, and signing in merges them (syncWith: an empty phone takes the backup's).
