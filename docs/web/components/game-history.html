GameHistory

Finished games of Play, kept on the phone in one JSON file: when, how it was played, each player's round totals and names.

Used when
A game of Play finishing; Home → History; signing in (the backup)

A GameRecord holds when the game finished, the mode, the length, each player's round totals, the players' names (format version 2, 2026-10-19; version 1 files still read, as Player 1 / Player 2), the game type (version 3, 2026-10-20: written only for Precision and Three targets, so a Scoring game is written as before) and, for a Live test game, the recording's name. Totals and the winner are worked out from the rounds, never stored.

FileGameHistory keeps them in game_history.json in the app's own support folder (path_provider). Each save goes to a .tmp file that then replaces the old one, one save at a time. A file that can't be read is renamed, never deleted, and the history starts afresh.

Since accounts Task 4 (2026-10-19), gameHistoryProvider is a SyncedGameHistory around the file: the phone stays the source of truth (offline-first), and while someone is signed in each add, delete and clear also reaches their backup (a RemoteGameStore), without waiting. sync() merges both ways by game id on sign-in. Known limit: a game deleted while signed out comes back at the next sync. Signed out, nothing leaves the phone.
