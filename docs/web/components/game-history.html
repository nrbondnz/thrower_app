Finished games of Play, kept on the phone in one JSON file: when, how it was played, each player's round totals.

A GameRecord holds when the game finished, the mode, the length, each player's round totals and, for a Live test game, the recording's name. Totals and the winner are worked out from the rounds, never stored.

FileGameHistory keeps them in game_history.json in the app's own support folder (path_provider). Each save goes to a .tmp file that then replaces the old one, one save at a time. A file that can't be read is renamed, never deleted, and the history starts afresh.

Behind an interface, so a backend can keep the games instead once there are accounts (backlog #4). Nothing leaves the phone today.
