judgeQuickDraw

The winner rule: the first knife to stick wins. A bounce-out or a false start loses; the same frame is a draw; if nobody sticks, there's no winner.

Type
Function
Defined in

Used when
Once both throws are in (or time is up)

Each throw is timed from go to its impact. A knife that reaches its board before go is a false start, however fast.
