judgeQuickDraw and QuickDrawMatch

A round's winner: the first knife to stick. A bounce-out or a false start loses; on the same frame the higher score wins, the same score is a draw; if nobody sticks, there's no winner. The live Quick draw is a match of three rounds.

Used when
Once both throws are in (or time is up)

Each throw is timed from go to its impact. A knife that reaches its board before go is a false start, however fast.

QuickDrawMatch (2026-10-19, the rules of Nigel's brother; the European Duel Cup format) keeps each round's winner: all three rounds are thrown, the player with more rounds won wins, extra rounds settle a level match, and Finish match ends it early (level: a draw). It sits in the scoring layer and takes only a round's winner, so it doesn't depend on the game layer.
