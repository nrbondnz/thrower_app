StartSignal

The live Quick draw's start, like Formula 1: 5 beeps a second apart with a light each, a random pause, then a long go beep as the lights go out.

Type
ChangeNotifier
Defined in
lib/game/start_signal.dart
Used when
Start, on the live Quick draw

The pause is one of 1.0, 1.2 … 3.0 s, picked at random each duel, so nobody can time it. Watching starts 1 s before go: a knife any earlier is an obvious false start.

goAt is read on the camera's own clock (TargetCamera.now) when the go beep is asked to play, so go and the frames are compared on one clock.
