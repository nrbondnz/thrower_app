Wiring · Component

Providers

The one place the layers are wired together. Each layer sits behind a provider, so a test overrides it with a fake.

Type
Riverpod providers
Defined in
lib/providers.dart
Used when
Read and watched by the screens

cameraProvider is shared by Calibrate and Play, and plays a Live test recording when recordingChoiceProvider picks one. The live Quick draw has its own liveQuickDrawCameraProvider, which asks for 60 fps and is released when the screen closes. Neither camera is retried automatically.

CalibrationNotifier and GameNotifier hold the session's state: the locked rings, and the game's rounds (a Match: a game per player, for the mode chosen in playModeProvider).
