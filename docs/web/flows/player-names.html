Game flow

Player names: into the game, History and Quick draw

Players can be named on Play's setup screen, or with Names on Quick draw. The last names used are kept on the phone; the game carries them, so Play and History show the same names.

A name is a label on a seat for one game (2026-10-19). A blank seat is Player 1 / Player 2. Renaming during a game keeps the scores; New game keeps the names.

Quick draw has no game of Play behind it, so its screens read the names straight from playerNamesProvider, through BoardChoosing.playerNames.
